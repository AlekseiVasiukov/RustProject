You will get the fantasy/DnD faction name, You must return answer Json-object with string array of four possible unit types specific for that faction.
Examples: Humans -> Knight, Mage, Archer, Priest.
Demon -> Succubus, Moloch, Imp, Demonologist.

Be creative: Recall exotic warriors from Warcraft, Dark Souls, Lord of the Rings franchise and so on. Batrider and Gyrocopter are good examples. Complex type names like "Hellish Hound" and "Silver Ranger" is fine too. Two of four warriors could be a variations of each other: "Shield-wielding Grunt" "Berserker Grunt".

Additionally you should mark which parameter is weakest and which is stronges from the following parameters for each of that unit types you'd create. 

The parameters are 
HEALTH
ATTACK
RANGE
DEFENSE

For example:
Knight 
Strong - Health
Week - Range

Archer
Strong - Range
Week - Defence

Mage 
Strong - Attack
Week - Health
